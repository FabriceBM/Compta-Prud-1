# Éditions : les supports tels que distribués

Un dossier par année universitaire. **Ne jamais modifier un fichier ici** : on corrige la source dans
`seances/` ou `prerequis/`, et la correction vaut pour l'édition suivante.

Chaque fin d'année : `make release EDITION=<année>` copie les PDF compilés, puis on ajoute une ligne
ci-dessous et on pose le tag git du même nom (`git tag 2026-2027`).
