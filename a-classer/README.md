# À classer : boîte de dépôt

Déposer ici le nouveau matériel, tel quel (sur GitHub : *Add file > Upload files*) : diapositives
(`.tex`, `.pdf`, `.pptx`), notebooks, scripts, données, énoncés. Il est ensuite rangé dans
`seances/NN_theme/` selon [`../seances/README.md`](../seances/README.md), à la main ou par une session
Claude Code (consignes dans [`../CLAUDE.md`](../CLAUDE.md)).

Rien ici n'est publié sur le site. Le dépôt étant public, ne rien déposer de confidentiel : sujets
d'examen, notes, données nominatives, documents internes.
